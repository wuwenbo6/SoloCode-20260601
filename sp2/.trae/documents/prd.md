## 1. 产品概述

NetFlow v9 收集器是一个网络流量监控工具，负责接收并解析 NetFlow v9 协议数据包，动态管理模板刷新，支持同一模板 ID 在不同观测点下的字段重用，并通过 Web 前端实时展示各观测点的字段定义和流记录。
- 目标用户：网络运维工程师、安全分析师
- 核心价值：提供对 NetFlow v9 模板和流数据的可视化洞察，解决多观测点场景下模板冲突与解析难题

## 2. 核心功能

### 2.1 功能模块

1. **仪表盘页面**：全局统计概览、活跃观测点列表、实时流量速率
2. **观测点详情页面**：单观测点下的模板列表与字段定义、流记录表格、字段类型筛选

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 仪表盘 | 统计卡片 | 显示已接收数据包总数、活跃模板数、活跃观测点数、流记录总数 |
| 仪表盘 | 观测点列表 | 展示所有已注册观测点，含 Source ID、IP、最近活跃时间、模板数量 |
| 仪表盘 | 实时流量图 | 显示最近 60 秒的流记录接收速率（折线图） |
| 观测点详情 | 模板定义表 | 展示该观测点下所有模板，含模板 ID、字段数量、最后刷新时间 |
| 观测点详情 | 字段详情 | 展示选中模板的字段定义列表：字段类型（类型名+编号）、字段长度 |
| 观测点详情 | 流记录表 | 展示该观测点的流记录数据，列由模板字段动态生成，支持分页 |

## 3. 核心流程

用户打开仪表盘，查看全局统计和观测点列表；点击某个观测点进入详情页，查看该观测点下的模板定义（字段类型与长度）；选择某个模板后，查看根据该模板解析的流记录数据。

    "存储流记录" --> "通知前端更新"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青蓝 (#0F172A) 背景 + 青绿色 (#06B6D4) 强调色
- 次色调：琥珀色 (#F59E0B) 用于告警/高亮
- 按钮风格：圆角（rounded-lg）、轻微阴影、hover 渐变
- 字体：JetBrains Mono（数据展示）+ Noto Sans SC（中文 UI）
- 布局风格：左侧窄导航栏 + 右侧内容区，卡片式模块布局
- 图标风格：线性图标（lucide-react）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 仪表盘 | 统计卡片 | 4 列网格，深色卡片带渐变边框，大号数字 + 标签 |
| 仪表盘 | 观测点列表 | 表格，行 hover 高亮，点击跳转详情 |
| 仪表盘 | 实时流量图 | 折线图（recharts），深色背景，青绿色线条 |
| 观测点详情 | 模板定义表 | 可选中行表格，选中行高亮，显示字段数与刷新时间 |
| 观测点详情 | 字段详情 | 紧凑表格，字段类型用颜色标签标识（如 IP 用蓝色、端口用绿色） |
| 观测点详情 | 流记录表 | 动态列表格，虚拟滚动，支持分页 |

### 4.3 响应式设计

- 桌面优先设计，导航栏在小屏下折叠为汉堡菜单
- 统计卡片在窄屏下从 4 列变为 2 列
- 表格在窄屏下支持横向滚动
