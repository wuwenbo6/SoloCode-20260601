## 1. 产品概述

SIP Transaction 模拟器是一个交互式Web应用，用于可视化展示SIP协议中INVITE客户端事务的完整生命周期。用户通过前端按钮触发SIP事件（发送INVITE、收到1xx/2xx响应），实时观察状态机的状态转换过程（Calling → Proceeding → Completed → Terminated），并查看SIP消息日志。

- 目标用户：网络协议学习者、SIP开发者、通信工程师
- 核心价值：通过交互式模拟直观理解RFC 3261中INVITE客户端事务的状态机逻辑

## 2. 核心功能

### 2.1 功能模块

1. **状态机控制台**：中心化的状态转换可视化，展示当前状态、允许的事件、转换路径
2. **事件触发面板**：按钮组用于触发SIP事件（Send INVITE、Recv 1xx、Recv 2xx、Recv 3xx-6xx、Timer B触发等）
3. **消息日志流**：实时展示SIP消息收发记录，包含时间戳、方向、消息类型
4. **状态转换历史**：记录完整的状态转换链路，标注触发事件和时间

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 模拟器主页 | 状态机可视化 | 中心展示当前状态节点，高亮转换路径，动画过渡效果 |
| 模拟器主页 | 事件触发面板 | 根据当前状态动态启用/禁用事件按钮，显示合法事件 |
| 模拟器主页 | 消息日志流 | 按时间顺序展示SIP消息，区分发送/接收方向 |
| 模拟器主页 | 状态转换历史 | 时间线形式展示所有状态变更记录 |
| 模拟器主页 | SIP消息详情 | 点击日志条目查看完整SIP消息内容 |

## 3. 核心流程

用户打开页面后，状态机处于初始状态（Idle）。用户点击"Send INVITE"按钮，状态进入Calling。根据不同响应，状态机沿不同路径转换：

```mermaid
flowchart TD
    "Idle" -->|"Send INVITE"| "Calling"
    "Calling" -->|"Recv 1xx"| "Proceeding"
    "Calling" -->|"Recv 2xx"| "Terminated"
    "Calling" -->|"Recv 3xx-6xx"| "Completed"
    "Calling" -->|"Timer B"| "Terminated"
    "Proceeding" -->|"Recv 1xx"| "Proceeding"
    "Proceeding" -->|"Recv 2xx"| "Terminated"
    "Proceeding" -->|"Recv 3xx-6xx"| "Completed"
    "Completed" -->|"Timer D"| "Terminated"
    "Completed" -->|"ACK sent"| "Completed"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝/靛蓝色系（#1e3a5f, #2563eb），辅以琥珀色高亮（#f59e0b）表示活跃状态
- 按钮风格：圆角药丸按钮，发送类按钮为蓝色，接收类按钮为绿色，终止类为红色
- 字体：JetBrains Mono（代码/日志）+ Outfit（UI文字）
- 布局风格：深色主题仪表板，左侧状态机可视化，右侧控制面板和日志
- 图标风格：Lucide线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 模拟器主页 | 状态机可视化 | 深色背景，节点为圆形/胶囊形，活跃节点发光动画，转换箭头带动画 |
| 模拟器主页 | 事件触发面板 | 药丸按钮组，禁用态半透明，当前状态徽章 |
| 模拟器主页 | 消息日志流 | 等宽字体列表，发送消息左对齐蓝色，接收消息右对齐绿色 |
| 模拟器主页 | 状态转换历史 | 竖向时间线，节点标注状态名和触发事件 |
| 模拟器主页 | SIP消息详情 | 侧边抽屉或模态框，等宽字体显示完整SIP消息 |

### 4.3 响应式

- 桌面优先设计，大屏为左右分栏布局
- 平板/手机端切换为上下堆叠布局
- 触控优化：按钮足够大，日志区域可滚动

### 4.4 设计氛围

- 深色科技感仪表板，类似网络监控工具的风格
- 状态节点带脉冲发光效果
- 消息日志带终端/控制台感觉
- 整体氛围：专业、技术感、沉浸式
