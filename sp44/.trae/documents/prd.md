## 1. 产品概述

基于WebRTC和mediasoup SFU架构的安全视频会议平台，支持端到端加密、虚拟背景、屏幕共享和服务器端录制混流。面向对隐私安全有高要求的企业和团队用户，提供专业级远程协作体验。

- 解决传统视频会议缺乏端到端加密的安全隐患，实现每帧独立加密
- 通过SFU架构兼顾安全与性能，支持大规模多人会议

## 2. 核心功能

### 2.1 用户角色

| 角色 | 加入方式 | 核心权限 |
|------|----------|----------|
| 主持人 | 创建会议 | 管理参会者、开启录制、结束会议 |
| 参与者 | 输入会议ID加入 | 音视频通话、屏幕共享、虚拟背景 |
| 观众 | 输入会议ID加入 | 仅观看和收听，不可发布流 |

### 2.2 功能模块

1. **大厅页面**：会议创建/加入、会议ID展示、设备检测
2. **会议房间页面**：视频网格、控制栏、参与者列表、聊天面板

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 大厅页面 | 会议创建 | 输入用户名，选择摄像头/麦克风，创建新会议获取会议ID |
| 大厅页面 | 会议加入 | 输入会议ID和用户名，加入已有会议 |
| 大厅页面 | 设备预览 | 预览摄像头画面和麦克风音量，选择音视频设备 |
| 会议房间页面 | 视频网格 | 自适应网格布局展示所有参与者视频，支持焦点模式 |
| 会议房间页面 | 控制栏 | 麦克风开关、摄像头开关、屏幕共享、虚拟背景、录制、离开会议 |
| 会议房间页面 | 参与者面板 | 展示参与者列表，主持人可静音/移除参与者 |
| 会议房间页面 | 聊天面板 | 文字消息实时聊天 |
| 会议房间页面 | 加密状态 | 显示端到端加密状态和密钥指纹验证 |

## 3. 核心流程

### 3.1 创建/加入会议流程

用户进入大厅页面 → 输入用户名 → 选择设备并预览 → 创建/加入会议 → 信令交换 → mediasoup传输建立 → 端到端加密握手 → 进入会议房间

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深邃黑蓝（#0a0e27），科技感深色主题
- 辅助色：青绿高亮（#00e5a0），用于活跃状态和强调
- 按钮风格：圆角半透明玻璃态（glassmorphism），悬浮时发光
- 字体：标题使用 Space Grotesk（科技感），正文使用 DM Sans（可读性）
- 布局：顶部工具栏 + 中间视频网格 + 底部控制栏
- 图标风格：线性图标（lucide-react），2px线宽

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 大厅页面 | 会议创建/加入 | 居中卡片布局，深色渐变背景，玻璃态卡片，发光按钮 |
| 大厅页面 | 设备预览 | 圆角视频预览框，设备选择下拉，音量指示条 |
| 会议房间页面 | 视频网格 | 自适应网格，圆角视频卡片，悬浮显示名称和状态 |
| 会议房间页面 | 控制栏 | 底部居中浮动玻璃态栏，圆形图标按钮，活跃状态发光 |
| 会议房间页面 | 参与者面板 | 右侧抽屉面板，半透明背景，列表项悬浮效果 |
| 会议房间页面 | 聊天面板 | 右侧抽屉面板，消息气泡，输入框自动聚焦 |
| 会议房间页面 | 加密状态 | 顶部小标签，锁形图标+绿色=已加密，黄色=验证中 |

### 4.3 响应式设计

- 桌面优先设计，大屏2-4列视频网格
- 平板自适应2列网格，面板叠为浮层
- 手机单列网格，控制栏简化为图标

### 4.4 动效设计

- 页面进入：卡片淡入上浮（fade-in + translateY）
- 加入会议：视频网格项逐个弹入（stagger animation）
- 控制栏按钮：悬浮时发光扩散，点击时缩放反弹
- 面板展开：从右侧滑入 + 遮罩淡入
- 加密状态：锁图标旋转解锁动画
