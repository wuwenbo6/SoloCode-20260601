## 1. 产品概述

基于Web的专业音频多轨编辑器，支持MP3/AAC格式解码、多轨波形可视化编辑、专业音频效果处理及WAV导出。目标用户为音乐制作人、播客创作者、音频工程师，提供浏览器内的专业DAW级编辑体验。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 完整使用所有编辑、效果处理、导出功能 |

### 2.2 功能模块
1. **音频导入模块**：WebCodecs解码MP3/AAC，拖拽上传
2. **多轨编辑模块**：波形可视化、轨道裁剪、移动、静音、独奏
3. **效果器链模块**：压缩器、均衡器、限制器（AudioWorklet实现）
4. **播放控制模块**：实时监听、旁通切换、播放/暂停/定位
5. **导出模块**：WAV格式导出、XML项目文件保存/加载

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主编辑页 | 顶部工具栏 | 新建/保存/加载项目、导入音频、导出WAV |
| 主编辑页 | 多轨时间轴 | 波形渲染、轨道拖拽、裁剪调整、缩放控制 |
| 主编辑页 | 轨道控制面板 | 音量/声像调节、静音/独奏按钮、效果器链入口 |
| 主编辑页 | 效果器面板 | 压缩器/均衡器/限制器参数调节、旁通切换 |
| 主编辑页 | 播放控制栏 | 播放/暂停、进度条、时间显示、监听开关 |

## 3. 核心流程

用户上传音频文件 → WebCodecs解码为音频缓冲区 → 渲染波形到多轨时间轴 → 拖拽调整轨道位置和长度 → 为轨道添加效果器并调节参数 → 实时监听效果 → 导出处理后的WAV文件 / 保存XML项目文件

```mermaid
flowchart LR
    A["导入音频文件"] --> B["WebCodecs解码"]
    B --> C["渲染波形到多轨"]
    C --> D["编辑轨道（裁剪/移动）"]
    D --> E["添加效果器链"]
    E --> F["调节效果参数"]
    F --> G["实时监听预览"]
    G --> H["导出WAV/保存XML"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深灰色背景 (#1a1a2e)，科技蓝高亮 (#00d4ff)
- **辅助色**：轨道颜色区分（紫/绿/橙/青），警告色橙红 (#ff6b35)
- **按钮风格**：扁平化圆角按钮，悬停发光效果，按下凹陷反馈
- **字体**：JetBrains Mono（等宽，专业感）作为主要字体，配合Inter
- **布局**：三栏布局（轨道控制 + 时间轴主区域 + 效果器面板），深色专业DAW风格
- **图标**：SVG线性图标，统一2px描边，科技感风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主编辑页 | 顶部工具栏 | 深色渐变背景、图标按钮组、项目名称输入框 |
| 主编辑页 | 多轨时间轴 | Canvas波形渲染、网格背景、拖拽手柄、选区高亮 |
| 主编辑页 | 轨道控制面板 | 卡片式设计、音量滑块、状态指示灯 |
| 主编辑页 | 效果器面板 | 旋钮控件、频谱可视化、Bypass切换开关 |
| 主编辑页 | 播放控制栏 | 居中大播放按钮、进度条带刻度、时间码显示 |

### 4.3 响应式
- Desktop-first设计，最小支持宽度1280px
- 效果器面板可折叠适配较窄屏幕
- 触控设备支持双指缩放时间轴

### 4.4 交互细节
- 波形缩放：滚轮缩放，平滑过渡动画
- 轨道拖拽：半透明预览，磁吸对齐
- 旋钮调节：环形进度指示，数值实时显示
- 播放时：播放头红色垂直线，波形动态高亮
