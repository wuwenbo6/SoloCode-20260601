## 1. 产品概述

基于BLE信标的室内定位与导航系统，通过扫描Eddystone/iBeacon信标获取RSSI信号，利用三边定位算法和卡尔曼滤波实现用户实时位置追踪，并在SVG室内地图上展示。支持点击地图目标点进行最短路径导航，以及信标坐标配置管理。

- 目标用户：商场、博物馆、医院等大型室内场所的管理员和访客
- 核心价值：解决GPS在室内无法定位的痛点，提供亚米级室内定位与智能路径导航

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 默认登录 | 管理信标配置、编辑路径图、查看定位数据 |
| 访客 | 免登录 | 扫描定位、查看地图、路径导航 |

### 2.2 功能模块

1. **定位大厅页面**：BLE信标扫描、实时位置显示、SVG室内地图交互、路径导航
2. **信标管理页面**：信标注册/编辑/删除、坐标配置、信号状态监控
3. **路径编辑页面**：路径图节点与边的可视化管理、路径预览

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 定位大厅 | BLE扫描面板 | 启动/停止BLE扫描，显示已发现的信标列表（UUID、RSSI、距离估算） |
| 定位大厅 | SVG室内地图 | 绘制楼层平面图，显示信标位置图标，实时渲染用户位置点（带卡尔曼平滑轨迹），点击地图设置导航目标 |
| 定位大厅 | 导航路径 | 点击目标点后，基于Dijkstra算法计算最短路径，在地图上高亮显示路径线段，显示预计距离 |
| 信标管理 | 信标列表 | 展示所有注册信标的UUID、名称、坐标、楼层信息，支持增删改查 |
| 信标管理 | 信标注册表单 | 输入信标UUID、名称、X/Y坐标、楼层、信号衰减参数，保存到数据库 |
| 路径编辑 | 节点编辑 | 在地图上点击添加路径节点，拖拽调整位置，删除节点 |
| 路径编辑 | 边编辑 | 连接两个节点创建路径边，设置边的权重（距离），删除边 |

## 3. 核心流程

用户打开系统后，前端通过WebBluetooth API扫描周围BLE信标，获取各信标的UUID和RSSI值。RSSI经过卡尔曼滤波平滑处理后，结合数据库中预存的信标坐标，通过三边定位算法计算用户当前位置。位置点实时渲染在SVG室内地图上。

当用户点击地图上某目标点时，系统基于预定义的路径图（图结构），使用Dijkstra算法计算从用户当前位置到目标点的最短路径，并在地图上高亮显示导航路线。

管理员可通过信标管理页面注册新信标，输入UUID和坐标信息；通过路径编辑页面维护路径图的节点和边。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝黑 (#0A1628) 作为背景，象征室内空间的科技感
- 辅助色：青蓝 (#00D4FF) 用于定位点和导航路径，橙色 (#FF6B35) 用于信标标记和警告
- 按钮风格：圆角微凸起，半透明玻璃拟态（glassmorphism）
- 字体：标题使用 Orbitron（科技感显示字体），正文使用 Noto Sans SC（中文正文）
- 布局风格：左侧面板 + 右侧地图画布的经典工具布局
- 图标风格：线条图标（lucide-react），细线条描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 定位大厅 | BLE扫描面板 | 半透明深色侧栏，扫描按钮带脉冲动画，信标列表带信号强度条形图，RSSI数值用颜色编码（绿-黄-红） |
| 定位大厅 | SVG室内地图 | 深色背景上的浅灰楼层平面图，信标用橙色菱形标记，用户位置用青蓝色圆点+脉冲动画，导航路径用青蓝色虚线+流动动画 |
| 定位大厅 | 导航信息卡 | 玻璃拟态浮动卡片，显示目标名称、预计距离、预计时间 |
| 信标管理 | 信标列表 | 表格布局，行悬停高亮，操作按钮内联，信号状态指示灯 |
| 信标管理 | 信标注册表单 | 模态对话框，坐标输入带地图点击选取 |
| 路径编辑 | 节点/边编辑 | 地图上可拖拽节点，连线模式切换按钮，属性面板在侧栏 |

### 4.3 响应式设计

- 桌面优先设计，左侧面板在移动端折叠为底部抽屉
- 地图画布支持鼠标拖拽平移和滚轮缩放
- 触屏设备支持双指缩放和单指拖拽

### 4.4 设计氛围

- 整体氛围：控制中心/指挥中心的科技感，深色主题，信息密度高但不杂乱
- 地图上的位置点和路径带有微妙的发光效果，营造全息投影的视觉感受
- 信标信号强度用渐变圆环表示，形成"信号覆盖"的直观视觉
