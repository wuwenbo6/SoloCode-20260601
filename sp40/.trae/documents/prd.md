## 1. 产品概述

基于WebTransport的实时机器人遥操作系统，支持通过浏览器远程控制模拟机器人（配备摄像头、机械臂、轮子），实时查看视频流和传感器数据，并通过三维模型可视化机器人状态，同时提供力反馈交互体验。

- 目标用户：机器人开发者、研究人员、远程操作场景用户
- 核心价值：零安装、低延迟的浏览器端机器人遥操作方案，结合3D可视化与触觉反馈

## 2. 核心功能

### 2.1 功能模块

1. **控制台主页**：3D机器人模型、视频流、传感器面板、控制面板、力反馈面板

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 控制台主页 | 3D机器人视图 | Three.js渲染机器人三维模型，根据关节角度实时更新姿态，支持旋转/缩放查看 |
| 控制台主页 | 视频流面板 | 接收并解码H.264视频流，实时显示机器人摄像头画面 |
| 控制台主页 | 传感器面板 | 实时显示IMU数据（加速度、角速度、姿态角）和电池电量，带动态仪表盘 |
| 控制台主页 | 控制面板 | 发送轮子速度命令、机械臂关节角度命令、期望力矩命令，支持滑块和数值输入 |
| 控制台主页 | 力反馈面板 | 显示期望力矩vs实际力矩对比，通过Gamepad API震动或鼠标力反馈生成触觉反馈 |
| 控制台主页 | 连接状态 | 显示WebTransport连接状态、延迟、数据吞吐量 |

## 3. 核心流程

用户通过浏览器连接到Go后端的WebTransport服务器，前端发送控制命令（速度、关节角度、期望力矩），后端模拟机器人执行并回传H.264视频流和传感器数据（IMU、电池），前端实时更新3D模型、视频画面和传感器显示。力反馈闭环：前端发送期望力矩→后端模拟执行→回传实际力矩→前端生成触觉反馈。

```mermaid
flowchart TD
    "用户操作" --> "前端控制面板"
    "前端控制面板" --> "WebTransport发送命令"
    "WebTransport发送命令" --> "Go后端接收"
    "Go后端接收" --> "机器人模拟执行"
    "机器人模拟执行" --> "生成视频流+传感器数据"
    "生成视频流+传感器数据" --> "WebTransport回传"
    "WebTransport回传" --> "前端接收"
    "前端接收" --> "3D模型更新"
    "前端接收" --> "视频解码显示"
    "前端接收" --> "传感器面板更新"
    "前端接收" --> "力反馈对比"
    "力反馈对比" --> "Gamepad/鼠标触觉反馈"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色工业风（#0A0E17 深蓝黑底色 + #00FF88 霓虹绿高亮 + #FF3366 警告红）
- 次色调：#1A1F2E 面板背景、#2A3040 边框
- 按钮风格：圆角矩形，悬停时霓虹绿发光效果
- 字体：JetBrains Mono（数据/代码）、Orbitron（标题/仪表盘）
- 布局：左侧3D视图+视频，右侧控制面板+传感器，底部状态栏
- 图标风格：线性科技风

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 控制台主页 | 3D机器人视图 | 深色背景、网格地面、机器人模型、关节高亮、旋转控制 |
| 控制台主页 | 视频流面板 | 深色边框、分辨率标签、帧率指示器、全屏切换 |
| 控制台主页 | 传感器面板 | 圆形仪表盘（IMU）、条形进度条（电池）、实时曲线图 |
| 控制台主页 | 控制面板 | 滑块组（速度/角度）、数值输入框、发送按钮、紧急停止按钮 |
| 控制台主页 | 力反馈面板 | 双柱状图（期望vs实际）、力矩仪表盘、反馈强度滑块 |
| 控制台主页 | 连接状态 | 连接指示灯、延迟数值、吞吐量图表 |

### 4.3 响应式设计

桌面优先设计，1920x1080为基准分辨率。侧边面板可折叠，3D视图自适应缩放。

### 4.4 3D场景指引

- 环境：深色太空/工业风环境，微弱环境光
- 灯光：主方向光 + 点光源高亮机器人关节
- 相机：透视相机，可轨道控制旋转缩放
- 构图：机器人居中，网格地面延伸至远方
- 交互：鼠标拖拽旋转、滚轮缩放、点击关节高亮
- 后处理：辉光效果（Bloom）增强霓虹感
