## 1. 产品概述

无人机FPV（第一人称视角）实时视频流传输与控制系统，模拟无人机相机通过GStreamer产生RTMP源，后端将H.264视频流通过WebTransport转发至FPV眼镜端Web页面，实现低延迟实时视频观看、OSD飞行数据叠加显示、视频录制保存为MP4、以及手机陀螺仪头追控制云台功能。

- 目标用户：无人机FPV飞行爱好者、无人机开发者与测试人员
- 核心价值：基于Web技术栈实现完整的FPV体验，无需原生应用，跨平台可用

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |

| 飞手 | 操作无人机，观看FPV画面，操控云台 |
| 观察者 | 仅观看FPV画面与遥测数据（可选扩展） |

### 2.2 功能模块

1. **视频流管理页（后端控制台）**：启动/停止GStreamer模拟源、查看连接状态、遥测数据面板

3. **头追控制页（手机端）**：陀螺仪数据采集与发送、连接状态指示

## 3. 核心流程

### 3.1 视频流传输流程

1. 后端启动GStreamer管道，模拟RTMP源产生H.264视频流
2. 后端将H.264 NAL单元通过WebTransport推送给已连接的FPV眼镜客户端
3. FPV眼镜页接收H.264数据，使用WebCodecs API解码
4. 解码后帧绘制到Canvas上渲染显示
5. 同时后端通过WebTransport数据通道推送遥测数据
6. 前端解析遥测数据叠加OSD显示

```mermaid
flowchart TD
    "GStreamer RTMP模拟源" --> "Go后端 RTMP接收"
    "Go后端 RTMP接收" --> "H.264 NAL解析"
    "H.264 NAL解析" --> "WebTransport视频流推送"
    "WebTransport视频流推送" --> "FPV眼镜页 WebCodecs解码"
    "FPV眼镜页 WebCodecs解码" --> "Canvas渲染"
    "Go后端遥测模拟器" --> "WebTransport数据通道"
    "WebTransport数据通道" --> "OSD叠加渲染"
    "Canvas渲染" --> "可选: MediaRecorder录制"
```

### 3.2 头追控制流程

1. 手机端打开头追控制页，请求陀螺仪权限
2. 监听DeviceOrientation事件获取alpha/beta/gamma角度
3. 通过WebSocket将角度数据发送至Go后端
4. Go后端转发云台角度至GStreamer管道（模拟云台控制）
5. FPV眼镜页显示当前云台角度状态

```mermaid
flowchart LR
    "手机陀螺仪" --> "DeviceOrientation API"
    "DeviceOrientation API" --> "WebSocket发送角度"
    "WebSocket发送角度" --> "Go后端"
    "Go后端" --> "云台控制模拟"
    "Go后端" --> "FPV眼镜页角度状态显示"
```

### 3.3 视频录制流程

1. 用户点击录制按钮
2. 前端使用MediaRecorder API捕获Canvas流
3. 录制过程中显示录制时长指示
4. 用户停止录制后，自动生成MP4文件并下载

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：工业科技风 / 航空HUD风格
- **主色**：深灰黑底（#0a0e17），霓虹绿强调（#00ff88），琥珀色警告（#ff9500）
- **辅助色**：青色（#00d4ff）用于信息，红色（#ff3b30）用于告警
- **按钮风格**：圆角矩形，微发光边框，半透明背景
- **字体**：等宽字体（JetBrains Mono / Source Code Pro）用于数据，标题用 Rajdhani
- **布局**：全屏沉浸式，视频占满视口，OSD悬浮叠加
- **图标**：线性图标，发光效果，航空仪表盘风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 视频流管理页 | GStreamer控制 | 深色面板，状态指示灯（绿/红），启动/停止按钮 |
| 视频流管理页 | 连接监控 | 连接数计数器，客户端列表 |
| 视频流管理页 | 遥测面板 | 数字仪表盘风格，数值实时跳动 |
| FPV眼镜页 | 视频渲染 | 全屏Canvas，16:9比例适配 |
| FPV眼镜页 | OSD叠加 | 左上：高度/速度；右上：GPS；左下：电池；右下：信号；底部：录制状态 |
| FPV眼镜页 | 录制控制 | 浮动按钮，录制时红色闪烁圆点 |
| FPV眼镜页 | 头追状态 | 右上角云台角度指示器（十字准星样式） |
| 头追控制页 | 陀螺仪采集 | 3D手机模型随角度旋转，实时角度数值 |
| 头追控制页 | 状态指示 | 顶部连接状态条，底部角度数值面板 |

### 4.3 响应式设计

- 桌面端优先：FPV眼镜页全屏沉浸体验
- 手机端适配：头追控制页针对移动端优化，大按钮与触控友好
- 平板端：视频管理页在中等屏幕上自适应布局

### 4.4 动效设计

- OSD数值变化：数字滚动过渡动画
- 连接状态：脉冲发光动画
- 录制指示：红色圆点呼吸闪烁
- 云台角度：平滑插值跟随
- 页面切换：淡入淡出过渡
